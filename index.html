How QR Doodle works

A QR code stores your message as codewords (8 modules each), split into Reed-Solomon blocks. Each block can repair a limited number of damaged codewords: roughly half its error-correction codewords. If you paint over a module and it ends up a different colour than the encoder wanted, that whole codeword counts as damaged. Painting a module the colour it already was costs nothing.

  • Required modules (blue tint) are finder, timing, alignment, format and version patterns. Scanners need them, so they're locked by default.
  • Painted modules (purple) are your drawing. The ones marked with a red dot differ from the natural code and use up budget.
  • Damaged codewords are shaded red. The status panel shows how many each block has against its limit. The code fails when any single block runs out.
  • Use spare capacity: when your message is shorter than the version holds, the leftover padding codewords can be anything. QR Doodle solves for padding values that make your drawing "naturally" correct. Larger versions give you more room for a logo.
  • Mask → Best for my drawing tries all 8 masks and picks the one that costs the least budget.
  • Compare densities tries the same logo across versions and error-correction levels so you can pick a winner.
  • Test with real decoders runs the exported image through jsQR (bundled) and, where the browser supports it, the native BarcodeDetector.
